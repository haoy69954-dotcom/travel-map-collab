# 旅伴地图 HarmonyOS 5+ 原型

这是面向鸿蒙 NEXT／HarmonyOS 5 及以后的 ArkTS 工程，不是 Android APK。应用直接全屏打开旅行地图的开屏动画；点击进入后显示注册或登录，成功后显示项目列表。隐私政策在注册表单中确认，原生层仅在主页面连接失败时显示重试入口。网站的登录、旅行和群聊数据仍保存在现有 CloudBase 服务。

用 DevEco Studio 打开此目录可继续开发和构建。当前网址是 CloudBase 的测试域名，正式发布前应更换为不会显示测试提示的稳定 HTTPS 地址。还需要在鸿蒙设备或模拟器上检查高德地图、登录状态、帖子外链、图片上传、行程导出与分享。

华为开发者中心已创建同包名应用，工程已有本地签名配置用于模拟器测试，但尚未提交应用市场。腾讯云默认测试域名会显示“确定访问”提示，按腾讯云规则只有绑定自定义域名才能去掉。正式公开发布前还需完成真机测试、应用备案或其他适用资质、内容举报处理流程和发布资料。当前核心功能仍为网页承载，公开上架前还须核对华为对简单网页封装应用的审核要求。签名私钥与 CSR 应仅保存到已被 Git 忽略的 `signing/` 目录，绝不能提交到仓库。

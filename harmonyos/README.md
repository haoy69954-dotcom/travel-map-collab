# 旅伴地图 HarmonyOS 5+ 原型

这是面向鸿蒙 NEXT／HarmonyOS 5 及以后的原生 ArkTS 工程，不是 Android APK。当前包含原生欢迎页、加载和重试入口，并通过 ArkWeb 打开现有旅行地图网站。网站的登录、旅行和群聊数据仍保存在现有 CloudBase 服务。

用 DevEco Studio 打开此目录可继续开发和构建。当前网址是 CloudBase 的测试域名，正式发布前应更换为不会显示测试提示的稳定 HTTPS 地址。还需要在鸿蒙设备或模拟器上检查高德地图、登录状态、帖子外链、图片上传、行程导出与分享。

此工程尚未签名，也未提交华为应用市场。上架前需要开发者实名认证、应用备案或其他适用资质、隐私政策与联系信息、内容举报处理流程，并在 AppGallery Connect 中完成签名与发布资料。具体以华为开发者中心对该应用的审核要求为准。

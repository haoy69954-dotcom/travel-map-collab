# 旅伴地图 HarmonyOS 5+ 原型

这是面向鸿蒙 NEXT／HarmonyOS 5 及以后的 ArkTS 工程，不是 Android APK。当前包含原生隐私同意、欢迎、加载和重试入口，并通过 ArkWeb 打开现有旅行地图网站。网站的登录、旅行和群聊数据仍保存在现有 CloudBase 服务。

用 DevEco Studio 打开此目录可继续开发和构建。当前网址是 CloudBase 的测试域名，正式发布前应更换为不会显示测试提示的稳定 HTTPS 地址。还需要在鸿蒙设备或模拟器上检查高德地图、登录状态、帖子外链、图片上传、行程导出与分享。

华为开发者中心已创建同包名应用，但工程尚未签名，也未提交应用市场。无需购买域名即可继续开发和邀请测试；正式公开发布前需考虑自定义域名与适用备案，并完成真机测试、应用备案或其他适用资质、内容举报处理流程和发布资料。当前核心功能仍为网页承载，公开上架前还须核对华为对简单网页封装应用的审核要求。签名私钥与 CSR 应仅保存到已被 Git 忽略的 `signing/` 目录，绝不能提交到仓库。

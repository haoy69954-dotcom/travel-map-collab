# 免费试用与正式发布的顺序

当前使用 CloudBase 分配的测试地址，不购买域名。它适合开发、真机试用和问题排查；正式公开发布前再决定品牌域名。换域名时要同步更新 `entry/src/main/ets/pages/Index.ets` 的网站地址、重新签名并提交新版本。

## 邀请测试前

1. 使用开发者账号生成并妥善保管签名私钥、CSR、调试证书和 Profile。私钥密码只由账号本人持有，不输入聊天，不提交 GitHub。
2. 在 DevEco Studio 中打包并签名，安装到 HarmonyOS 5+ 真机或模拟器。
3. 验证首次隐私同意前没有联网地图加载；同意后能进入网站，拒绝后不能使用联网功能。
4. 验证注册登录、创建旅行、邀请加入、地点搜索、地图详情、评论与群聊同步、酒店与逐日路线、照片、举报、屏蔽、账号删除，以及高德路线跳转。
5. 用真机实际界面制作截图，并按后台要求提交邀请测试版本。测试账号和测试数据与正式用户数据隔离。

## 正式发布前

1. 核对备案、隐私政策、第三方地图披露和用户内容管理要求。
2. 将测试地址替换为长期可用的 HTTPS 地址；若购买域名，完成实名认证、备案和绑定。域名后续仍可更换，但需更新应用版本。
3. 避免把只有网页封装的原型当成完成版提交公开审核；补齐鸿蒙端体验，并通过真机测试。
4. 准备正式发布证书和 Profile，填写华为应用信息、隐私政策链接、真实截图、测试账号，提交审核。

# 隐私政策编写所需的功能与数据清单

这是根据当前代码核对的事实清单。网站展示的隐私政策草稿位于 `public/privacy.html`；运营者姓名与联系邮箱已由开发者确认。正式发布前仍需核对实际部署地区、云存储备份清理周期，以及外部服务的最终配置。

| 功能 | 涉及的数据 | 使用目的 |
| --- | --- | --- |
| 注册和登录 | 昵称、邮箱、加密保存的密码校验值、会话标识 | 创建账号、识别用户与保持登录 |
| 旅行协作 | 项目名称、日期、成员、地图起点、地点、评论、群聊消息、投票、行程、图片和参考链接 | 让受邀旅伴共同规划旅行 |
| 在线状态 | 旅行内的成员标识和最近活跃时间 | 向同一旅行的成员显示在线状态 |
| 举报和屏蔽 | 举报者、被举报内容、原因、被屏蔽账号 | 处理不当内容与个人屏蔽设置 |
| 本机设置 | 面板宽度、群聊已读位置 | 保存界面偏好和未读状态 |

当前鸿蒙工程只申请网络访问权限；地图位置由用户搜索或选择。代码中没有读取手机 GPS 定位的调用。

外部服务与资源：腾讯云 CloudBase 托管网站和数据，高德地图提供地图、地点搜索及路线；无高德配置时可回退 OpenStreetMap。网站在取得同意后才加载 Google Fonts 与 unpkg 的 Leaflet 资源。用户贴入小红书或大众点评链接时，服务端会尝试读取帖文标题和封面，或将相应页面作为外部链接打开。正式发布前要按实际配置复核各服务可能收到的 IP 地址、设备或网络信息。

当前公开邀请链接持有者可以打开旅行内容预览；请在发布前决定是否收紧为仅成员可见。删除账号时，服务端会移除该用户账号、会话、发布的地点、评论、群聊消息和不再使用的本地上传图片；云存储备份的保留规则需进一步核对。

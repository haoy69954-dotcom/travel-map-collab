# 华为应用市场发布文案草稿

应用名称：旅伴地图

一句话介绍：把想去的地方放在地图上，和旅伴一起讨论、安排每天的路线。

应用介绍：

旅伴地图是为结伴旅行设计的共享地图。创建旅行并邀请伙伴后，大家可以搜索餐厅、景点和酒店，把想去的地点标在同一张地图上。每个地点都有独立的讨论区，也可以在群聊中继续交流。确定要去的地点后，可按日期安排路线、查看路程和预计时间，并将路线导出到高德地图。旅行计划也可生成带地图的行程图片。

主要功能：

- 地图上共同收藏、查看和讨论地点。
- 将餐厅、景点、酒店按类别与日期整理。
- 每日路线规划、交通方式选择和预计路程。
- 群聊、评论同步、在线状态与未读提醒。
- 从小红书和大众点评链接补充地点参考资料。
- 账号登录、举报与屏蔽、账号删除。

发布前核对：以上描述应以鸿蒙设备上的实际测试结果为准；截图必须从真实运行画面制作。不要把 CloudBase 测试域名版本提交审核。

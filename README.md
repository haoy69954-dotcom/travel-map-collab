# 旅伴地图

一个以地图为中心的多人旅行讨论原型。创建旅行后，伙伴通过同一链接加入，在应用内群聊、提出地点、围绕地点回复和表态，再把确定的地点安排进日程。

完整的产品对象、流程和状态规则见 [PRODUCT_LOGIC.md](./PRODUCT_LOGIC.md)。

iPhone 原型工程见 [ios/README.md](./ios/README.md)。它已具备原生加载、外部链接打开和系统分享入口；目前还未完成构建、真机验证或 App Store 提交。

## 运行

需要 Node.js 22 或更新版本。项目不需要安装依赖。

```bash
npm start
```

打开 `http://localhost:4173`。先看到多人乘车的开屏动画，点击「进入旅伴地图」后登录或注册；登录后进入项目首页，可创建新旅行或打开已加入的旅行。地图左上角的 Home 键可直接返回项目首页；未登录时也可从登录页打开首页，登录后查看自己的项目。创建旅行时可输入国内城市、车站或具体地址，搜索并确认地图起点。首次没有项目时可打开京都示例旅行。

若使用自己的高德 Web 端 JS API Key，在项目根目录创建仅供本机使用的 `.env.local`：

```text
AMAP_JS_KEY=你的Web端Key
AMAP_SECURITY_CODE=你的安全密钥
```

`.env.local` 已被忽略，不会作为项目源码交付。安全密钥保存在服务器，并经同源代理用于高德 JS API；Web 端 Key 会按高德的加载方式传给浏览器。修改配置后重启服务器。

## GitHub 与公网部署

GitHub 用于保存源码和运行自动测试；GitHub Pages 只托管静态文件，不能运行本项目的登录、群聊、图片上传和数据保存接口。要让朋友通过公网使用，需要另外部署 Node.js 服务。仓库已提供 `Dockerfile`，可放到支持 Docker 和**持久化磁盘**的主机运行。

部署时设置 `HOST=0.0.0.0`、平台提供的 `PORT`，并将 `DATA_DIR` 指向持久化目录（容器默认 `/app/data`）。将 `AMAP_JS_KEY` 和 `AMAP_SECURITY_CODE` 配成服务端环境变量；不要上传 `.env.local`、`data/`、`sources/` 或 `exports/`。高德 Web 端 Key 还需为正式域名配置授权。首次部署的数据库为空，不会自动带上本机已有账号和旅行；如需迁移，必须单独、安全地复制数据目录并做好备份。

上线前应先决定服务器和持久化存储方案。只把仓库推到 GitHub 不会生成可供多人使用的网站地址。

使用腾讯云 CloudBase 云托管时，按 [CloudBase 部署说明](./CLOUDBASE_DEPLOY.md) 配置专用 Dockerfile、端口及持久化存储。

将同一旅行链接发给其他人即可加入同一空间。首次进入可用邮箱、昵称和密码注册；之后登录同一账号即可在项目首页找回已加入的旅行。邀请链接会作为待加入项目显示在首页。未登录不能加入、添加地点、评论和群聊。在本机测试多人同步时，可以用两个浏览器窗口打开链接。服务器会把旅行数据保存在 `data/state.json`，账号和登录会话保存在 `data/auth.json`；账号文件在首次注册后创建，两个文件都位于被忽略的 `data/` 目录。

## 当前可用

- emoji 乘车开屏动画与动态贴纸风格、邮箱注册与登录、项目首页、新建旅行、已有旅行集合、地图 Home 键、登录后加入邀请、复制邀请链接
- 点击加号后在地图上落点，提出地点或单独标记酒店；点击地图空白处关闭地点详情
- 旅行群聊与地点讨论，可从群聊消息定位关联地点
- 每人对地点表态；推进地点状态并安排到某个 Day
- 地点、吃、玩、酒店、按 Day 分区的行程、活动六个视图；吃/玩页只显示对应地图标记
- 地图标记显示评论数与评论者；缩小时切换为图标和聚合标记
- 吃/玩地点可在列表中直接换 Day，并根据现有地点与酒店起终点查看顺路建议；确认前预览路线变化
- 每天可选择出发酒店和结束酒店；支持手动调整顺序或一键“顺路排”，预览后保存
- 国内行程使用高德底图和驾车道路规划，展示距离与预计时间；可查附近高德地点并查看资料
- 一次点击生成并复制当天或整趟旅行的全部站点与高德导航链接，按高德官方链接限制分段打开
- 地点详情可展示成员补充的地址、营业时间、费用和参考资料
- 地点卡片与详情都有图片区域；可上传照片，公开链接有封面时会尝试带入，无照片时显示占位插画
- 添加或编辑地点时可粘贴小红书、大众点评链接；能读取的公开标题、摘要、封面及结构化地址、时间、价格会预填，缺失项可手动补充
- 详情中显示来源帖子预览；酒店和餐饮价格突出显示
- 实时同步、在线成员提示、断线重连
- 桌面和手机布局

## 产品化之前

网站已经部署在腾讯云 CloudBase；本地运行方式仍可用于开发。账号密码使用服务器端哈希保存，写入操作按登录账号确认身份；邮箱目前只作登录名，没有邮件验证或找回密码功能。已有的旧昵称成员没有可验证的账号凭据，原有内容会保留，但注册后需要作为新成员加入。正式运营前还需可靠数据库、邮件验证与密码找回、通知、地点搜索服务、地图服务配额、内容治理与备份。

配置高德 Key 后，中国大陆旅行使用高德 JS API 地图、附近地点查询和驾车道路规划；京都等海外旅行使用 OpenStreetMap 底图和直线示意。高德境外地图及路线需要额外服务权限，当前 Key 未具备该权限。路线变化预览先显示直线估算，高德道路计算返回后更新为道路距离与预计时间。高德官方 URI 导航链接每段最多支持一个途经点，因此多站行程会生成连续分段链接，不能直接写入高德 App 中的一条完整路线或账户收藏。正式运营时还需处理地图服务配额、权限、备份和高德使用条款。

小红书和大众点评可能要求登录或验证码，公开网页也不一定包含地点资料；此时保留原链接并显示可点击的预览卡，不会把验证页面当成帖子。当前没有接入读取任意小红书笔记全文的官方接口，因此无法保证在应用内完整展示原帖。地址、营业时间、价格是可选信息，自动带入后仍应核对。
